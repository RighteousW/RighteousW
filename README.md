# Righteous Wasambo

Computer Science (Honours) graduate from the University of Namibia (Upper Second Class, 2:1), based in Malawi. I build software across backend systems, Linux infrastructure, and AI-assisted accessibility, with an emphasis on practical tools and well-documented engineering.

## Selected projects

### [Sign Avatar](https://github.com/RighteousW/sign_avatar)
Honours research prototype exploring bidirectional speech and sign-language communication for healthcare accessibility. Combines computer vision, speech processing, language components, and avatar visualization; broader support for Namibian Sign Language remains limited by available datasets.

**Stack:** Python, OpenCV, PyQt6, machine learning

### [serve](https://github.com/RighteousW/serve)
A lightweight C command-line tool for managing projects as Linux `systemd --user` services. Uses per-project `.serve` configurations to register, inspect, pause, resume, and stop services without managing each one manually.

**Stack:** C, Linux, systemd

### [Distributed Task Runner](https://github.com/RighteousW/distributed_task_runner)
A master-worker task execution prototype using TCP sockets, asynchronous I/O, worker discovery, heartbeats, and retry handling.

**Stack:** Python, asyncio, TCP sockets, JSON

### [Custom Data Indexer](https://github.com/RighteousW/custom_data_indexer)
A Trie-based text indexer supporting exact and prefix search, persistent indexes, and a command-line interface.

**Stack:** Python, data structures and algorithms
